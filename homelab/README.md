# Homelab

This directory owns cross-machine architecture, networking and services. Future topology and service records should distinguish observed deployments from proposed designs.

Reference [machine records](../machines/README.md) for hardware, identities and addresses, [runbooks](../runbooks/README.md) for procedures, and [service configuration](../configs/services/README.md) for reusable definitions. Do not maintain a second inventory here.

The [service catalog](services/README.md) owns documented service purposes and relationships, linked to canonical machine observations. Batch 2A adds the [current verified relationship index](networking/topology.md) and [qualified historical cases](incidents/README.md); older topology/role proposals do not become implemented infrastructure.

Reusable network and remote-access procedures live in the [runbook index](../runbooks/README.md). Historical cases own their original reported outcomes and uncertainties; the current relationship index references confirmed records without creating a second machine/address inventory.
