# Platform mappings

Platform mappings implement capabilities from [profiles](../profiles/README.md), with explicit release/architecture applicability and verified package/configuration choices.

- [Debian](debian.md)
- [Ubuntu](ubuntu.md)
- [Proxmox](proxmox.md)
- [Raspberry Pi](raspberry-pi.md)

These are intentionally unfilled placeholders. A Debian-derived Proxmox host must not automatically inherit workstation/desktop configuration. Raspberry Pi hardware does not by itself identify its installed OS.
