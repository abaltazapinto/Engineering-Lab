# Roadmap

## Phase 1 — baseline and documentation
- Establish the Debian host baseline and record package choices.
- Create a standard lab layout for services, networking, and backups.

## Phase 2 — containers and local automation
- Standardize container runtime usage between Docker and Podman.
- Capture compose and podman-compose examples for repeatable deployments.

## Phase 3 — observability and remote access
- Deploy Prometheus and Grafana for metrics and dashboards.
- Use Tailscale to secure access to lab services.

## Phase 4 — edge and embedded systems
- Add Raspberry Pi and embedded device notes.
- Document MQTT messaging patterns and device onboarding.
